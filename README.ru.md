# CommitLatch — первая рабочая версия

CommitLatch записывает попытки внешних действий агента, проверяет потерянные
результаты и блокирует повтор, если безопасность повторения не установлена.

## Уже реализовано

Версия 0.1.0a2: добавлены HTTP-демо с потерей ответа и нативной идемпотентностью,
27 тестов и проверенный пример LangGraph без вызовов LLM.

```sh
PYTHONPATH=src python3 -m commitlatch http-demo
```

Методика: [HTTP_DEMO](docs/HTTP_DEMO.md). Интеграция: [LANGGRAPH](docs/LANGGRAPH.md).

- Python SDK без сторонних зависимостей во время выполнения.
- Локальный журнал SQLite: намерения, попытки, подтверждения и сверка.
- Привязка бизнес-ключа к неизменным параметрам и идентичности адаптера.
- Возврат сохранённого результата без повторной операции.
- Блокировка неизвестных исходов и явный повтор только доказанно невыполненной операции.
- Атомарные захваты задач и отклонение позднего результата старого worker.
- CLI для просмотра, сверки тестовой операции и воспроизведения журнала.
- Демонстрация с настоящим аварийным завершением дочерних процессов.
- Открываемый в браузере отчёт с раскрывающимися журналами.

## Запуск

Из папки проекта, Python 3.9+:

```sh
PYTHONPATH=src python3 -m commitlatch demo --directory demo-output
```

Папка должна быть новой или пустой. Откройте `demo-output/report.html`.
Ключи API и установка серверов не нужны. Демонстрация работает только с тестовыми данными.

В трёх сценариях worker завершается после сохранения эффекта в отдельной базе
тестового сервиса, но до сохранения подтверждения в журнале CommitLatch.

| Сценарий | Результат | Операций в тестовом сервисе |
|---|---|---:|
| Слепой повтор | Дубликат | 2 |
| Сверка по подтверждению | SUCCEEDED | 1 |
| Проверка результата недоступна | UNKNOWN, повтор заблокирован | 1 |

Это результаты конкретного теста. Они не являются сравнением с правильно
настроенным Temporal и не доказывают свойства настоящих платёжных API.

## Границы первой версии

Это локальная alpha, а не законченный production-продукт. PostgreSQL, Stripe
sandbox, интеграция с Temporal, автоматизация согласований и облако ещё не
реализованы. Текущий replay показывает записанные события, но не восстанавливает
произвольную программу или состояние LLM.

Если результат неизвестен, библиотека может остановить процесс до ручного
разбирательства. Автоматически безопасно повторить любой внешний запрос невозможно.
Локальная блокировка также не отменяет уже отправленный запрос старого worker.
